# מערכת הזמנות ספק (סביבת טסט)

אתר Next.js + Postgres. שלב 1: ספקים, פריטים, שיוך פריט-ספק, מק"ט ספק, תמונות לפי מק"ט, יבוא CSV מ-ERP.

## הרצה מקומית
```
npm install
cp .env.example .env.local      # להגדיר DATABASE_URL של מסד הטסט
npm run db:setup                # יצירת טבלאות (db/schema.sql)
npm run db:seed                 # נתוני דוגמה (לטסט בלבד)
npm run dev
```

משתמשי טסט (מה-seed, סיסמה `test1234` או `SEED_PASSWORD`): admin (מנהל), buyer (רכש), store (מחסן), viewer (צפייה).
בסביבת ייצור חובה להגדיר `SESSION_SECRET` ולהחליף סיסמאות.

## מסכים
- `/suppliers` ספקים: חיפוש, הוספה ידנית, עריכה, השבתה, שיוך פריטים עם מק"ט ספק ומחיר
- `/items` פריטים: חיפוש לפי מק"ט/שם/ברקוד/מק"ט ספק, הוספה ידנית, הורדה והחזרה (מחיקה רכה)
- `/sku-match` טבלת התאמת מק"ט ספק למק"ט שלנו
- `/quotes` הצעות מחיר: דשבורד פתוחות/באיחור, יצירת בקשה לספק, שליחה במייל (mailto), מסמך להדפסה/PDF, הזנת מחירים שהספק הציע, מחיקה רכה עם סיבה ושחזור
- `/orders` הזמנות רכש: דשבורד פתוחות/באיחור/שווי פתוח, הזמנה עם או בלי הצעת מחיר, עדכון כמויות ומחירים עם היסטוריה, מסמך PDF ומייל, ביטול
- `/receiving` קבלת סחורה: לפי הזמנה (מלאה או חלקית), ללא הזמנה, שורות לפי מק"ט שלנו או מק"ט ספק, קליטה, עדכון וביטול קליטה עם היסטוריה
- `/discrepancies` ריכוז אי התאמות: חוסר/עודף כמות, מחיר שונה, פריט שלא הוזמן, מק"ט לא מזוהה, קבלה ללא הזמנה; סימון כמטופל עם הערה
- `/users` משתמשים והרשאות לפי תפקיד (מנהל, רכש, מחסן, צפייה). כל פעולה שמשנה נתונים בודקת הרשאה בשרת
- `/import` יבוא CSV של ספקים, פריטים ושיוך, והעלאת תמונות לפי שם קובץ = מק"ט
